# Mohit Raj — Developer & AI/ML Research Portfolio

Personal portfolio website showcasing my research internship at **IIT Kharagpur**, autonomous AI agents, LLM fine-tuning work, full-stack MERN applications, competitive programming metrics, and achievements.

🌐 **Live Website:** [mohit-portfolio-gamma.vercel.app](https://mohit-portfolio-gamma.vercel.app)

---

### 🛠️ Tech Stack
- **Frontend:** React 19, Vite, Tailwind CSS, Framer Motion, React Icons
- **Integrations:** GitHub Activity Calendar, Live LeetCode Stats Card
- **Deployment:** Vercel (CI/CD via GitHub)

---

### ✨ Key Sections & Features
- **Hero & Resume:** Overview of AI/ML research and engineering focus with direct 1-page PDF resume download (`/Resume.pdf`).
- **About & Focus Areas:** Highlights experience in Multi-Agent Reinforcement Learning (MATD3), autonomous LLM agents (`smolagents`, `LangGraph`), and full-stack development.
- **Featured Projects:** Showcases the GAIA Benchmark Autonomous CodeAgent, Multi-Agent Research Pipeline, Llama-2 7B LoRA/QLoRA fine-tuning, AI Journal System, MealConnect, and AgroTech AI.
- **Problem Solving & GitHub Activity:** Displays official LeetCode contest & acceptance metrics alongside live GitHub contribution graphs.
- **Achievements & Credentials:** Covers GATE 2026 (DA & CS), IIT Kharagpur Research Internship, Hugging Face Agents Course Certificate of Excellence, Amazon ML Summer School, and IOQM Merit.
